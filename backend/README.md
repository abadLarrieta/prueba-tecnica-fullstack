# Prueba Técnica Full Stack

API REST desarrollada como parte de la prueba técnica de Desarrollo Full Stack.

## Tecnologías

- Node.js
- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- Jest

## Descripción

Este proyecto implementará una API REST para la gestión de tareas, permitiendo crear, consultar, actualizar y eliminar tareas.

Cada tarea contará con:

- ID
- Título
- Descripción
- Estado de completado
- Fecha de creación

La API contará además con un mecanismo de autenticación para proteger sus rutas.
